# حمزاوي سات — Admin Panel v0.3

لوحة أدمن عربية RTL متصلة بالـBackend v0.2/Termux.

## تشغيل محليًا
```bash
npm install
npm start
```
ثم افتح:
`http://127.0.0.1:3001`

## عنوان الـBackend
من شاشة الدخول يمكن تعديل عنوان الـAPI واختبار الاتصال.
الافتراضي:
`http://127.0.0.1:3000/api`

هذه النسخة لا تغيّر الـBackend؛ هي واجهة الأدمن فقط.
